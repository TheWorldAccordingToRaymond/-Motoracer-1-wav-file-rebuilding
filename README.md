# -Motoracer-1-wav-file-rebuilding

**"Motoracer 1" wav file rebuilding (Reserved for true fans)**

*Thanks to Dosia who gave the solution on forum.xentax.com (Closed, unfortunately.)*

	In "Motoracer 1", sounds are packed in the file data\SFX.BKF
	They are easily extracted 
		with Dragon Unpaker <"https://sourceforge.net/projects/dragonunpacker/">
		or Game Extractor <href="https://sourceforge.net/projects/gameextractor/"> etc...
	The files obtained are not quite .wav, therefore unreadable as they are, these are raw data to which is added a sawtooth.
	SFX.BKF contains 8 bit and 16 bit files, here we will only deal with 16 bit.

Motoracer1_wav_rebuild.html and Motoracer1_wav_rebuild.py do the same job.
